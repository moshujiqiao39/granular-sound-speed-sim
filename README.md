# 颗粒物质声速虚拟仿真实验

水平放置、水平加载，用时差法和压力传感器测量玻璃珠、钢珠中的纵波声速。页面里可以改样品、载荷、间距、信号和材料参数，用示波器光标采集数据，并完成直线拟合、名义压强换算和高压区赫兹标度计算。

这是 2026 年上海市大学生物理实验竞赛（创新）速强团队实验的可交互版本。拟合结果在浏览器里按最小二乘法重算。

## 打开方式

安装和构建都不用做。

- 克隆本仓库后，用浏览器打开 `index.html`。
- 或在仓库目录执行 `python -m http.server`，然后访问本地地址。

在线页面：<https://moshujiqiao39.github.io/granular-sound-speed-sim/>

## 页面里有什么

1. **导览**：目的、步骤、装置和器材。
2. **原理**：时差法、相关系数、斜率标准差、压强换算、赫兹接触推导。
3. **虚拟实验台**：样品管、力链、双通道示波器。可调温度、质量、管内径、间距、频率、幅度、耦合剂、回程差和读数噪声。
4. **数据处理**：本次测量和原实验数据都能改。实时给出声速、r、s<sub>m</sub>，以及 ln v–ln P 的幂指数，并可导出 CSV。
5. **高压仿真**：按 P → F → δ → k<sub>n</sub> → E<sub>eff</sub> → v 计算，检验 1/6 标度，并叠加 20 kPa 以下的实测点。
6. **讨论**：根据当前数据生成结论，并保留误差来源、成本和参考文献。

空气声速使用 `v = 331.3 + 0.606θ`。名义压强默认 `g = 9.80 m/s²`、管内径 `80 mm`，4 kg 对应约 7798.6 Pa。颗粒在弱压强下的声速按已测曲线取值；配位数、体积分数和传力效率会按赫兹标度或 ηP 修正。高压曲线与粒径无关，这是公式本身的结果。
